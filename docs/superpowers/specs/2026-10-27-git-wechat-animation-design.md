# Git 代码时光机：微信聊天动画设计

> 目标判据：华为 ICT 1.4 实验手册、用户“只使用免费资源”的约束以及 `code-rules`。

## 目标

用单文件 `index.html` 制作一个 375×720 的微信风格聊天动画，并通过连续提交展示 Git 的版本管理能力。项目主体是 Git 操作练习，动画用于提供可视化载体。

## 版本轨迹

1. `v1 静态聊天界面`：标题栏、时间分割线、对方消息、自己的消息和微信绿色气泡。
2. `v2 消息自动播放动画`：七句对话循环播放，发送前显示三点输入状态，并自动滚动到底部。
3. `v3 优化细节与主题`：药丸式时间线、气泡尾巴、柔和阴影和绿色输入状态。
4. `v3 后改坏并回退`：临时把气泡改成刺眼红色，不提交，使用 `git checkout --` 或 `git reset --hard HEAD` 恢复。
5. `feat-neon` 分支：从 v3 创建独立分支，将绿色气泡改成霓虹渐变并强化标题栏赛博朋克风格。

## 交互与视觉

- 页面居中显示手机外框，尺寸 375×720；背景使用柔和的灰绿渐变。
- 标题栏显示“码道小助手”，包含返回箭头、更多菜单和微信风格状态栏。
- 对方消息靠左白气泡，自己的消息靠右绿色气泡；气泡带朝向头像的小尾巴。
- 时间分割线为灰底圆角药丸。
- 消息逐条弹出，输入状态先显示三个跳动圆点，再替换为实际消息。
- 动画每轮结束后停顿并循环播放。
- 遵循 `prefers-reduced-motion`，减少动画时直接显示完整对话。

## 文件结构

- `index.html`：结构、样式、脚本和动画数据。
- `test-ui.py`：Playwright 浏览器验收，检查静态内容、消息增长和响应式页面。
- `README.md`：操作方式、Git 历史、分支与验证命令。
- `docs/PROJECT_MEMO.md`、`docs/CODE_MAP.md`：交接与代码地图。

## 验证

- v1：页面能打开，显示两条初始消息和微信绿色气泡。
- v2：JavaScript 自动追加七句消息，输入状态出现，聊天区自动滚动。
- v3：时间药丸、气泡尾巴、阴影和绿色输入状态正常。
- Git：`git log --oneline --graph --all` 能看到 v1、v2、v3 和 `feat-neon`。
- 浏览器控制台无错误。
