# 项目：微信聊天动画 Git 时间机器

> 最后更新：2026-10-27

## 项目总览

- 目标：完成华为 ICT 1.4 练手题，用微信聊天动画练习 Git 本地版本管理和特性分支。
- 技术栈：HTML5、CSS、原生 JavaScript、Python Playwright。
- 运行：在本目录启动 `python -m http.server 8100 --bind 127.0.0.1`，打开 `http://127.0.0.1:8100`。
- 测试：`python test-ui.py`。
- 入口：`index.html`。
